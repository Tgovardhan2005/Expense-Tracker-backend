# Expense Tracker Backend 💲

This repository contains the backend code for the Expense Tracker application. It is built using Node.js, Express.js, and MongoDB, and provides APIs for managing expenses, user authentication, and data storage.

## Features
- **Add Expense**: API to add new expense entries.
- **Edit Expense**: API to update existing expense entries.
- **Delete Expense**: API to remove expense entries.
- **View Expense History**: API to fetch expense data for analysis.
 
## Setup Instructions

### Prerequisites
- Node.js installed on your system.
- MongoDB database set up.

### Steps to Set Up
1. Clone this repository:
   ```bash
   git clone https://github.com/Tgovardhan2005/Expense-Tracker-backend.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Expense-Tracker-backend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the server:
   ```bash
   npm start
   ```

---

## API Endpoints
The following APIs are available:

### Expense APIs
- **POST /api/expenses**: Add a new expense.
- **PUT /api/expenses/:id**: Edit an expense.
- **DELETE /api/expenses/:id**: Delete an expense.
- **GET /api/expenses**: Fetch all expenses.
